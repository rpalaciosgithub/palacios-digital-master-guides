📱 iPhone Setup & Safety

How to install and use on iPhone
  1. Upload this one HTML file to a webpage served over HTTPS (for example GitHub Pages). Opening an HTML file directly in Files or a file:// address is not a reliable way to access the camera.
  2. Open the HTTPS webpage in Safari on your iPhone.
  3. Tap Start Camera. When Safari asks, choose Allow to give this website camera access (and microphone access if requested for video).
  4. Tap Take Photo or Start Auto for one picture every 30 seconds. Tap STOP Auto to stop.
  5. To record, tap Start Recording, then Stop & Save Clip. Videos appear in the gallery, where you can save them.
  6. Optional: in Safari use Share → Add to Home Screen for an app-like icon. Open that icon to use your hosted app.

If Safari does not allow the camera

Check you opened an HTTPS address, allow the website camera permission in Safari's website settings, and make sure another app is not using the camera. You can also check Settings → Apps → Safari → Camera on supported iOS versions. Reload and try again.


Important limitations

This app cannot secretly control the camera, bypass Safari permissions, or reliably capture in the background or with your phone locked. Keep Safari open in the foreground and your screen awake. Auto mode pauses when you leave the page and must be restarted. Videos depend on Safari's MediaRecorder support and may not work on older iPhones. Long recordings consume substantial memory; save often. This app does not upload your pictures anywhere.
