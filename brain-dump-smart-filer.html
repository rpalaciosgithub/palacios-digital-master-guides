2. Capture your thoughts

How to use tags＋ Open− Close

You can type or click a tag, then write your note. Add more tags and notes as needed, then click Organize & save. Each note goes to its own file.

Example — on the same line:

@todo    call dentist

Or — on the next line:

@todo
call dentist

You can also use several tags in one brain dump:

@todo
call dentist

@quote  Our hearts are restless until they rest in you
From iPhone Voice Memos＋ Open− Close

Paste your transcript below, then click Convert spoken labels. Say “Song,” “To do,” or “App idea” before each note. Labels are recognized at the start of a line or a sentence, with a comma, a colon, or just a space. Example: Song: Bésame Mucho. To do: call the dentist. App idea: Spanish restaurant practice.

Review the results: transcription punctuation can vary, and a sentence beginning with a category word may need correction. Custom tag names work too. This converts text; it does not transcribe audio.

Tip: keep your RTF files closed in WordPad or Word while saving.

Where your notes will go

Preview before saving. Untagged notes and unknown tags go to Inbox.rtf. Nothing is filed until you click Organize & save.

Your tags & files

Add your own categories. @to do list, @to-do and @task also mean @todo. Tags are not case-sensitive.

Your custom tags are remembered by this browser on this computer, not stored inside your RTF files. If you open the app in a different browser, or clear your browsing data, you will need to add them again. Your notes are always safe, because they live in your folder. Removing a tag never deletes its RTF file or the notes in it.

Read a saved file

Read the current file from your connected folder. Open the RTF files in WordPad (if installed), Microsoft Word, or another RTF reader. Web links are clickable there; some readers use Ctrl+click. The preview below shows the text and links, not all document formatting.



How it works
Click a tag button or type a tag at the start of a line. Each tag begins a new entry; all following lines belong to it until the next tag. Email addresses inside a note stay untouched. To keep a line beginning with @ inside a note, type a backslash first: \@someone.
Each saved entry gets your computer’s local date and time. Within a batch, entries typed lower in the box are considered newer and appear first. Existing file contents stay below the new entries. Only files receiving notes are created. New entries use bold date headings, two blank lines below each heading, and 13-point body text. A− / A+ adjusts this app’s display, not the saved document font size.
Paste complete web addresses (https://…, http://…, or www.…); they become clickable links. When an RTF file is first created, any matching .txt file in this folder is imported below your new notes. The original .txt file stays in place. Later saves update the RTF file only. Close the file in Word or WordPad before saving more notes here.
Your draft and custom tags are remembered in this browser when local storage is available. A draft is not a filed note. Download your draft for a separate copy. No notes are sent to a server.
Use the downloaded HTML file in desktop Chrome or Edge. If file access is unavailable in a preview, download the app and open it directly in your browser. You can always download your draft.
