1. The Machine

START HERE
ÉL / ELLA / UD.
Learn this form as the base: habla
FOR TÚ
BASE + S
habla → hablas
FOR ELLOS / ELLAS / UDS.
BASE + N
habla → hablan
The shortcut: If you know the él / ella / usted form, you can usually build tú by adding S and ellos / ellas / ustedes by adding N. This works with regular verbs, stem-changing verbs, verbs with irregular yo forms, and many very irregular verbs.
Important: This machine teaches the relationship among these three present-indicative forms. Yo and nosotros/nosotras have their own patterns and are outside this machine.
